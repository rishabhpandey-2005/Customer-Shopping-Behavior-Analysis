# Customer Shopping Behavior Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior using transactional retail data to uncover insights related to spending patterns, customer loyalty, subscriptions, product performance, and purchasing trends. The objective was to help businesses make data-driven decisions for improving customer engagement, revenue generation, and marketing strategies.

The project combines:

* Python for data cleaning and preprocessing
* MySQL for business analysis using SQL
* Power BI for interactive dashboard visualization
* Gamma AI for business presentation and insight storytelling

---

## Dataset Information

* Total Records: 3,900+
* Features: 18 columns

### Dataset Includes:

* Customer demographics
* Purchase details
* Product categories
* Subscription status
* Discounts & promo usage
* Review ratings
* Shipping preferences
* Purchase frequency

## Data Preparation & Feature Engineering

Performed end-to-end data preprocessing and transformation using Python:

* Handled missing values and improved data consistency
* Applied median imputation for missing review ratings
* Standardized column names using snake_case formatting
* Created customer age groups and purchase frequency features
* Performed data validation and redundancy checks
* Integrated cleaned dataset with MySQL database for SQL analysis

## Key Insights

* Subscribers contributed significantly to repeat purchases and total revenue.
* Young Adult customers generated the highest revenue contribution.
* Express shipping customers showed higher average purchase amounts.
* Certain products demonstrated strong discount dependency behavior.
* Loyal customers represented the highest-value customer segment.
* Female customers generated slightly higher overall revenue compared to male customers.
